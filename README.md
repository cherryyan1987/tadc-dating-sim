## 🧠 About the Game

The Amazing Digital Dating Simulator (often called **TADC Dating Sim**) is a choice-driven visual novel where you interact with characters and explore different story routes.

Key features:
- Multiple romance routes  
- Branching dialogue choices  
- Multiple endings  
- Replayable gameplay
